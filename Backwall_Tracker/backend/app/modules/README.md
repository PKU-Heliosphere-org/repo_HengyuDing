# 后端功能模块

每个业务功能按 `router -> service -> model/schema` 演进，跨模块能力通过明确接口调用。

计划模块：

- `auth` / `users`：登录、用户和系统角色；
- `projects`：项目、成员、硬里程碑和计划版本；
- `tasks`：任务树、依赖、负责人和确认闭环；
- `today`：个人今日聚合与每日进展；
- `meetings`：会议及行动项；
- `imports`：图片/PDF 导入、解析任务和人工核对；
- `notifications`：站内提醒、升级与去重；
- `reports`：周报聚合和导出；
- `health`：当前已实现的服务探针。

未实现的模块不注册“假成功”接口；第一次交付真实能力时再增加对应包和路由。
