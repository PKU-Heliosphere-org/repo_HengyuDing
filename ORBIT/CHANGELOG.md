# ORBIT 更新记录

## v0.4 — 2026-11-13

软件版本号为 **0.4.0**。将当前完整工作区确认为 v0.4 发布基线，主要新增视角关键帧与固定画幅视频导出，保留 v0.3 的离线桌面、导入、行星、缓存播放等功能。

- 新增缓存模式下的“视角关键帧”，未启用缓存时灰显不可选。
- 时间轴新增关键帧轨道，支持当前时刻添加/更新、双击添加、点击跳转、拖动时间、删除及前后导航。
- 记录相机位置、观察中心、旋转和滚转、观察距离、视场角与缩放；方向采用四元数最短路径插值，距离和缩放按对数变化，采用缓入缓出，避免相反视角直接穿过观察中心。
- 暂停可调整和更新视角，播放与游标跳转自动应用插值；单帧及区间外保持端点。关闭开关保留帧数据。
- 项目新增可选关键帧字段及启用偏好，兼容没有这些字段的旧项目；保持 `schema_version=2`。增加非法关键帧校验，失败不替换当前工作区。
- 相机关键帧与对象跟随分开使用，关键帧使用世界坐标。
- 新增 MP4/H.264 视频导出：固定 16:9、9:16 或 1:1 画幅、720p/1080p，支持预览、24/30/60fps、视频时长、可选模拟时间与标签。
- 使用缓存区间逐帧绘制，包含视角关键帧、尾迹和场景表面，输出尺寸和时长不依赖窗口比例或实际渲染速度；界面侧栏、时间轴不进入视频。
- 本机 FFmpeg 流式编码，支持取消、临时文件清理及恢复导出前的相机和时间。缺少编码器时提示安装，不自动下载。

### 兼容性与使用

- 项目格式仍为 `schema_version=2`，读取格式 1、2；软件版本升级不改变项目格式。关键帧为可选字段，无关键帧的旧项目可直接打开。
- 相机关键帧最多 1000 帧，缓存最多 50 万个行星采样。导出区间需缓存就绪，视频时长 1–600 秒、最多 18000 帧。
- MP4 编码需要本机 FFmpeg/libx264，导出为无音轨 H.264/yuv420p；不自动安装或下载编码器。
- 缓存和视频参数不嵌入项目，关闭/重开后需重新准备缓存。导出只绘制三维场景，不包含时间轴或侧栏，画幅不依赖当前窗口大小。
- 沿用采样回放、显式中心/参考系和原始文件不变的原则；不新增导入对象动力学传播、自动参考系转换或 exe 安装包。

### 验证基线

功能冻结前最近一次验证：**后端全量 87 项、前端单元 33 项、同次浏览器定向回归 8 项及生产构建通过**。8 项包含视频 3、关键帧 1、缓存 2、工作台/项目 2，不代表全部 e2e 或原生 WebView2 手测。

实际检查了 720×1280 竖屏和 1280×720 地球表面跟随视频，均为 24fps、24 帧/1 秒；核实窗口变化不改变输出尺寸、首尾帧不同，以及取消、任务清理和原时间/相机恢复。

## v0.3 — 2026-11-12

软件版本号为 **0.3.0**。本版本将现有完整工作区确认为 v0.3 基线，沿用 Windows 本地桌面和离线星历架构。

### 区间缓存播放

- 时间轴上方新增“启用缓存渲染”，双端滑块选择播放范围，显示起止 UTC 和准备进度。
- 预先读取整个区间的位置、速度、姿态，并补齐起点之前的尾迹历史；全部完成后允许播放，区间内无需继续请求星历，实时绘制尾迹。
- 游标和播放限制在所选区间，终点停止，重播回到起点；视角、播放倍率和外观仍可调整。
- 范围、行星、场景坐标声明或尾迹历史需求变化时暂停并重新准备；支持失败重试、退出准备及忽略过期响应。
- 缓存在当前会话内存中保存，不嵌入项目；最多 50 万个行星采样，超过时提示缩短范围或减少行星。
- 修复普通播放越过尾迹窗口后隐藏尾迹的问题，以及历史预取阈值导致重复读取的问题。

### 显示与交互

- 时间轴支持拖动上沿调整高度、双击复位及键盘调整；滚动条采用与左栏一致的深色细条样式。
- 尾迹按真实时间渐细、渐暗，保留所选历史和缺测断点，宽度独立于轨道线宽；参考平面不会切出暗线。
- 光点大小表示内层光晕直径，默认 **6px**，范围 2–48px、步长 0.1px；整个光晕直径约为该尺寸的 4.55 倍。尾迹头部为光点尺寸的一半，默认 **3px**。
- 新添加的行星默认显示尾迹；启动时默认启用星空，恢复项目时保留保存的星空开关。
- 参考平面采用同心圆与每隔 30° 的径向线。
- 密切轨道及参数预览曲线的显示截断半径固定为 **100 AU**，移除“曲线半径”设置；不沿用旧项目的半径设置，不修改原始轨迹。

### 保留的导入与数据能力

- CSV/XLSX 六根数、位置与速度输入，统一保存状态向量；缺速度时需明确同意差分估计。
- 大源文件时间范围筛选、降采样、后台进度与取消；原始文件不变，清洗与筛选决策可随项目恢复。
- 八大行星本地星历、真实尺度纹理表面、昼夜光照、自由视角、聚焦与跟随，以及项目和 PNG 导出。

### 兼容性与验证

- 项目写入 `schema_version=2`，继续读取格式 1、2；软件版本号与项目格式版本分开。
- 已保存的光点数值继续保留，但按新的内层光晕尺寸定义显示；缺省字段采用新默认值。
- 不新增导入对象动力学传播、自动参考系转换、视频导出或安装包。
- 功能冻结前最近一次前端验证：**27 项单元测试、7 项定向浏览器回归及生产构建通过**，含真实星历、尾迹像素、缓存后停止取数、取消/重试和项目恢复。此为定向回归，不代表全部浏览器用例或原生 WebView2 手测。
- 后端此前全量基线为 68 项通过；版本标记更新时的检查另见本地 v0.3 实现记录。
